# How I solve every problem

1. **Restate** the problem in my own words and write 2-3 examples.
2. **Pseudocode**: write the steps in plain English, one line per step.
3. **Code**: translate each pseudocode line into Python.
4. **Test**: run the examples, then the edge cases (empty, one item, negatives).
5. **Complexity**: state time and space.
6. **Log**: write the pattern and my mistake in `PROBLEM_LOG.md`.
7. **Redo** after 3 days and again after 2 weeks.
