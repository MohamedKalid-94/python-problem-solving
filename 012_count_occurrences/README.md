# Problem 12 — Count Occurrences

## Problem

Count how many times a target number appears in a list without using `count()`.

## Input

```python
numbers = [10, 20, 10, 30, 10, 40, 20]
target = 10
```

## Output

```text
Target Occurrences = 3
```

## Approach

* Initialize `count` to `0`.
* Loop through each number.
* If the number matches the target, increment `count`.

## Pattern

**Counting Occurrences**

## Complexity

* **Time:** `O(n)`
* **Space:** `O(1)`
