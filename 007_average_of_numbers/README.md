# Problem 7 — Average of Numbers

## Problem

Calculate the average of numbers without using `sum()` or `len()`.

## Input

```python
numbers = [10, 20, 30, 40, 50]
```

## Output

```text
Average = 30.0
```

## Approach

* Use an accumulator to calculate the total.
* Use a counter to count the numbers.
* Calculate average using `total / count`.

## Pattern

**Accumulator + Counter**

## Complexity

* **Time:** `O(n)`
* **Space:** `O(1)`
