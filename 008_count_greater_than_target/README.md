# Problem 8 — Count Numbers Greater Than a Target

## Problem

Count how many numbers in a list are greater than a given target value.

## Input

```python
numbers = [12, 45, 7, 89, 23, 56]
target = 30
```

## Output

```text
Count = 3
```

## Approach

* Initialize `count` to `0`.
* Loop through each number.
* If the number is greater than the target, increment the counter.

## Pattern

**Condition + Counter**

## Complexity

* **Time:** `O(n)`
* **Space:** `O(1)`
