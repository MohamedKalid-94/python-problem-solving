# Python Problem Solving

A structured journey to improve my Python problem-solving skills through consistent practice.

## Goal

Build strong problem-solving ability for software engineering and AI/GenAI engineering roles.

The focus is not just on writing code, but on learning how to:

* Understand problems
* Break problems into smaller steps
* Think through solutions before coding
* Identify patterns
* Choose appropriate data structures
* Handle edge cases
* Debug code
* Analyze time and space complexity
* Explain why a solution works

## Learning Approach

For each problem:

```text
Understand
    ↓
Think manually
    ↓
Break into steps
    ↓
Pseudocode
    ↓
Code
    ↓
Test
    ↓
Debug
    ↓
Complexity analysis
    ↓
Identify the pattern
```

## Progress Principle

The goal is not to solve the maximum number of problems.

The goal is to gradually move from:

```text
Need solution
    ↓
Need hints
    ↓
Solve with guidance
    ↓
Solve independently
    ↓
Recognize the pattern
    ↓
Explain and optimize
```
