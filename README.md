# ▶️ Run the Project

Clone the repository

```bash
git clone <repository-url>
```

Go to the project

```bash
cd python-problem-solving
```

Create a virtual environment

```bash
python -m venv .venv
```

Activate

Windows

```bash
.venv\Scripts\activate
```

Linux / macOS

```bash
source .venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

# 🧪 Run Tests

Run all tests

```bash
pytest
```

Verbose output

```bash
pytest -v
```

Coverage

```bash
pytest --cov=code
```
