# Phase 1 - Step 3: Expressions & Operators

## Overview

Expressions and operators are the foundation of programming logic.

In Python, operators help us perform operations on data such as:

- Mathematical calculations
- Comparing values
- Combining multiple conditions
- Searching values
- Checking object identity
- Updating variables

Every real-world application uses expressions and operators internally.

Examples:

- Shopping bill calculation
- Salary processing
- Login validation
- Searching products
- Permission checking

## 4. Membership Operators

Used to check whether a value exists inside a collection.


Operators:



in

Examples:

- Product search
- Username validation
- Character search


---

## 5. Identity Operators

Used to compare object identity.


Operators:



is

is not


Difference:


==  → Compare values

is  → Compare memory identity


Examples:

- Reference checking
- Object comparison

Used to assign and update values.


Operators:

*=

Examples:
