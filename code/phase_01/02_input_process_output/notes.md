# Notes

## Universal IPO Structure

```
Read Input
↓
Store Input
↓
Process
↓
Display Result
```

---

## Every Programming Problem

1. What information do I need?
2. What calculations are required?
3. What should I display?

---

## Example

Input

```
Radius = 10
```

Process

```
Area = π × r²
```

Output

```
Area = 314.16
```

---

## Common Mistakes

❌ Mixing input and processing
❌ Hardcoding values
❌ Printing before calculation
❌ Forgetting variable names
❌ Wrong formula
