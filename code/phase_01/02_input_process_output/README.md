# 02 - Input → Process → Output Pattern

## Objective

Learn the fundamental programming pattern used in almost every software application:

Input → Process → Output (IPO)

This pattern helps you think like a programmer by breaking every problem into three simple steps.

---

## Topics Covered

- Reading input
- Processing data
- Producing output
- Data flow
- Program structure
- Variables
- Mathematical calculations

---

## IPO Pattern

```
Input
   ↓
Process
   ↓
Output
```

Every program follows this flow.

Example:

```
Input
Principal = 10000

↓

Process
Interest = Principal × Rate × Time / 100

↓

Output
Simple Interest = 1200
```
