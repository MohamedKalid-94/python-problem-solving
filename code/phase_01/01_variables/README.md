# 01 - Variables

## Objective

Learn how variables store data in Python and how they are used to solve programming problems.

---

## Topics Covered

- Variable declaration
- Naming conventions
- Data storage
- Variable reassignment
- Multiple variables
- Constants (by convention)

---

## Files

| File | Description |
|------|-------------|
| 01_student_info.py | Store and display student information |
| 02_employee_salary.py | Calculate employee salary |
| 03_area_rectangle.py | Calculate rectangle area |

---

## Learning Outcomes

After completing this folder, you will be able to:

- Create variables
- Store different data types
- Perform calculations
- Write meaningful variable names

---

## Problem Solving Pattern

**Input → Store → Process → Output**
