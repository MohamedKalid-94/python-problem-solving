# Phase 1 - Step 4: Decision Making

## Overview

Decision making is one of the most important concepts in programming. It allows a program to choose different actions based on conditions.

In Python, decision making is performed using conditional statements such as:

- `if`
- `if else`
- `if elif else`
- Nested `if`

As programs become more complex, we also use:

- Multiple conditions
- Guard clauses
- Decision-making patterns

These concepts are used in almost every real-world application, from login systems to banking software.

# Topics Covered

## 1. Simple if

Executes code only when a condition is True.

Examples:

- Positive number
- Even number
- Login status
- Temperature check

---

## 2. if else

Chooses between two possible outcomes.

Examples:

- Pass or Fail
- Even or Odd
- Voting eligibility
- Discount availability

---

## 3. if elif else

Handles multiple possible choices.

Examples:

- Grade calculation
- Ticket category
- Salary bonus
- Weather classification

---

## 4. Nested if

Places one `if` statement inside another.

Examples:

- Login with role
- Bank withdrawal
- Student admission
- Employee promotion

---

## 5. Multiple Conditions

Combines multiple conditions using:

- `and`
- `or`
- `not`

Examples:

- Voting eligibility
- Job application
- Credit card approval
- Exam eligibility

---

## 6. Guard Clauses

Handles invalid cases first to keep code simple.

Examples:

- Age validation
- Username validation
- Payment validation
- File validation

Benefits:

- Better readability
- Less nesting
- Easier maintenance

---

## 7. Decision Patterns

Common programming patterns for solving real-world problems.

Patterns:

- Validation
- Range Checking
- Category Selection
- Decision Tree
